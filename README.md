# Финансовый Telegram-бот 🤖

Умный бот для учёта доходов и расходов с AI-анализом. Просто напишите о транзакции в свободной форме — бот сам определит тип, сумму и категорию.

**Каждый пользователь разворачивает бота у себя — полная приватность данных.**

## ✨ Возможности

- 💬 **Свободный ввод** — пишите как хотите: "Обед 500", "Зарплата 50000"
- 💰 **Доходы и расходы** — автоматическое определение типа транзакции через AI
- 📊 **Сводки** — за неделю и за месяц с AI-анализом и балансом
- 💬 **Чат-режим** — задавайте вопросы о финансах на обычном языке
- 🗑️ **Управление данными** — очистка за период или полная очистка
- 🗑️ **Удаление аккаунта** — команда `/delete_data` для полного удаления данных
- 🔒 **Приватность** — данные хранятся только на вашем сервере

## 🚀 Быстрый старт (пошагово)

### Шаг 1: Подготовка

Вам понадобится:
- **Python 3.14+** — [скачать](https://www.python.org/downloads/)
- **Git** — [скачать](https://git-scm.com/)
- **Telegram аккаунт**

Проверьте установку:
```bash
python --version   # Должно быть 3.14 или выше
git --version
```

### Шаг 2: Скачайте код

```bash
# Клонируйте репозиторий
git clone https://github.com/ваш-ник/finance-bot.git

# Перейдите в папку проекта
cd finance-bot
```

### Шаг 3: Создайте виртуальное окружение

Это изолирует зависимости проекта от системы:

```bash
# Создайте окружение
python -m venv venv

# Активируйте его
# Windows PowerShell:
venv\Scripts\Activate.ps1

# Windows CMD:
venv\Scripts\activate.bat

# Linux/Mac:
source venv/bin/activate
```

Вы увидите `(venv)` в начале строки — значит окружение активно.

### Шаг 4: Установите зависимости

```bash
pip install -r requirements.txt
```

Установятся:
- `python-telegram-bot` — работа с Telegram API
- `python-dotenv` — загрузка настроек из `.env`
- `requests` — запросы к AI API

### Шаг 5: Создайте Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Введите **имя бота** (например: `Мой Финансовый Бот`)
4. Введите **юзернейм** (например: `my_finance_bot_123`) — должен заканчиваться на `bot`
5. BotFather выдаст **токен** — сохраните его (выглядит как `1234567890:ABCdef...`)

### Шаг 6: Получите свой Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Отправьте `/start`
3. Вы увидите свой **User ID** (например: `123456789`) — сохраните его

### Шаг 7: Настройте `.env`

```bash
# Скопируйте шаблон
copy .env.example .env    # Windows
# или
cp .env.example .env       # Linux/Mac
```

Откройте `.env` в любом редакторе и заполните:

```env
# Токен от BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ

# Ваш Telegram ID
BOT_ADMIN_ID=123456789

# Bridge API (AI)
BRIDGE_API_URL=https://example.com/v1/chat/completions
BRIDGE_API_KEY=your-api-key-here
BRIDGE_MODEL=model-name

# База данных (можно не менять)
DB_PATH=expenses.db
```

⚠️ **Важно:** Никогда не публикуйте `.env` файл — он содержит секреты!

### Шаг 8: Запустите бота

```bash
python main.py
```

Вы увидите:
```
🚀 Запуск бота для учёта расходов...
✅ Бот готов к работе!
Бот запущен: @my_finance_bot_123
```

### Шаг 9: Проверьте работу

1. Откройте вашего бота в Telegram
2. Нажмите **Start**
3. Напишите: `Обед 500 рублей`
4. Бот ответит с подтверждением расхода

🎉 **Готово!** Бот работает.

## 📱 Как пользоваться

### Запись транзакций

Просто напишите в свободной форме:

| Сообщение | Тип | Категория |
|-----------|-----|-----------|
| `Обед 500 рублей` | Расход | Еда |
| `Такси 350` | Расход | Транспорт |
| `Зарплата 50000` | Доход | Зарплата |
| `Получил от друга 1000` | Доход | Подарок |
| `Продукты в пятерочке 2000` | Расход | Еда |

### Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и главное меню |
| `/help` | Инструкция по использованию |
| `/week` | AI-сводка за прошлую неделю |
| `/month` | AI-сводка за прошлый месяц |
| `/all` | Список последних расходов |
| `/clear_week` | Удалить записи за неделю (с подтверждением) |
| `/clear_month` | Удалить записи за месяц (с подтверждением) |
| `/clear_all` | Удалить ВСЕ записи (с подтверждением) |
| `/delete_data` | Удалить аккаунт и все данные навсегда |

### Кнопки в главном меню

- 📊 **Сводка за неделю** — AI-анализ расходов и доходов за неделю
- 📈 **Сводка за месяц** — AI-анализ за месяц
- 💰 **Все расходы** — список последних транзакций
- 💬 **Чат** — свободное общение с AI о финансах
- ❓ **Помощь** — инструкция

### Вопросы к AI

Задавайте вопросы на обычном языке:
- `Сколько я потратил на еду в сентябре?`
- `Какой был баланс в августе?`
- `Какая самая большая трата?`
- `На что я больше всего трачу?`

## ☁️ Развёртывание 24/7

Чтобы бот работал постоянно, а не только когда включён ваш компьютер, разверните его на сервере.

### Вариант 1: VPS (Ubuntu) — Рекомендуемый

**Сервисы:** [Timeweb](https://timeweb.com), [Aeza](https://aeza.ru), [Hetzner](https://hetzner.com) (~300₽/мес)

```bash
# 1. Подключитесь к серверу
ssh root@ваш-ip

# 2. Обновите систему и установите Python
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip python3-venv git -y

# 3. Клонируйте репозиторий
git clone https://github.com/ваш-ник/finance-bot.git
cd finance-bot

# 4. Настройте виртуальное окружение
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 5. Настройте .env
nano .env
# Вставьте ваши токены (как в шаге 7 выше)

# 6. Создайте systemd сервис для автозапуска
sudo nano /etc/systemd/system/finance-bot.service
```

Содержимое `finance-bot.service`:
```ini
[Unit]
Description=Finance Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/finance-bot
Environment="PATH=/root/finance-bot/venv/bin"
ExecStart=/root/finance-bot/venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 7. Запустите сервис
sudo systemctl daemon-reload
sudo systemctl enable finance-bot
sudo systemctl start finance-bot

# 8. Проверьте статус
sudo systemctl status finance-bot

# 9. Посмотрите логи
sudo journalctl -u finance-bot -f
```

**Плюсы:** Дёшево, надёжно, автоперезапуск при падении.

### Вариант 2: Docker

```bash
# Сборка образа
docker build -t finance-bot .

# Запуск контейнера
docker run -d --name finance-bot --restart=always \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/.env:/app/.env \
  finance-bot

# Логи
docker logs -f finance-bot

# Остановка
docker stop finance-bot

# Удаление
docker rm finance-bot
```

**Плюсы:** Чистая изоляция, легко переносить между серверами.

## 🏗️ Архитектура проекта

```
finance-bot/
├── main.py          # Точка входа (запуск polling)
├── bot.py           # Логика бота (команды, обработчики, UI)
├── llm.py           # Клиент AI (Bridge API, парсинг транзакций)
├── database.py      # SQLite база данных (доходы, расходы, история)
├── periods.py       # Календарные периоды (неделя, месяц)
├── config.py        # Загрузка конфигурации из .env
├── .env.example     # Шаблон конфигурации (без секретов)
├── .gitignore       # Исключения для Git
├── Dockerfile       # Образ для Docker
├── requirements.txt # Python зависимости
└── README.md        # Этот файл
```

### База данных (SQLite)

Файл `expenses.db` создаётся автоматически. Содержит 3 таблицы:

| Таблица | Назначение |
|---------|-----------|
| `expenses` | Расходы (сумма, категория, описание, дата) |
| `incomes` | Доходы (сумма, категория, описание, дата) |
| `llm_responses` | История вопросов и ответов AI |

Данные разделены по `user_id` — каждый пользователь видит только свои записи.

## 🛠️ Решение проблем

### Бот не отвечает
```bash
# Проверьте, запущен ли бот
# В терминале должно быть "Бот запущен: @..."

# Проверьте токен в .env
# Он должен быть в формате: 1234567890:ABCdef...
```

### Ошибка `ModuleNotFoundError`
```bash
# Убедитесь, что виртуальное окружение активно (venv в начале строки)
venv\Scripts\Activate.ps1    # Windows
source venv/bin/activate      # Linux/Mac

# Переустановите зависимости
pip install -r requirements.txt
```

### Ошибка `401 Unauthorized` от Telegram
- Проверьте `BOT_TOKEN` в `.env`
- Токен должен быть точь-в-точь как выдал BotFather

### Ошибка подключения к AI API
- Проверьте `BRIDGE_API_URL` и `BRIDGE_API_KEY`
- Убедитесь, что интернет работает

### База данных не создаётся
- Проверьте права на запись в папку проекта
- Убедитесь, что `DB_PATH` в `.env` указывает на доступное место
